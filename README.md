# Personal Mini-Toolkit

A menu-driven Python command-line application that brings together variables, user input/output, conditionals, loops, and lists across three practical tools: **Quick Task List**, **Daily Expense & Budget Check**, and **Study Session Timer**.

## How to Run

1. Make sure Python 3 is installed on your machine.
2. Clone or download the repository (`plp-python-week8`).
3. Open a terminal in the project folder and run:
   ```bash
   python toolkit.py
